# Day 2 — Storybound Library

Open `Storybound_Library.ipynb` in Google Colab or Jupyter and run the cells from top to bottom. It installs its own dependencies and starts a Gradio demo.

Describe a story you want to read to get semantically matched suggestions from an 18-book sample catalog. Click one of the sample prompts to try it quickly. The availability and request flow are illustrative and are not connected to a real library.
