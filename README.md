# Samsung Innovation Campus — GenAI Course Tasks

This repository collects projects completed as tasks during the Generative AI (GenAI) course by **Samsung Innovation Campus (SIC) at my college**.

## Course work

### Day 1 — NEXUS HR Knowledge Assistant
A Streamlit retrieval-augmented generation (RAG) learning demo for searching HR policy documents. It uses sentence-transformer embeddings and FAISS semantic retrieval, with support for PDF, DOCX, and TXT uploads.

[Open the Day 1 project](Day%201%20-%20RAG%20Knowledge%20Assistant/)

### Day 2 — Storybound Library
A library discovery demo where readers describe a story, mood, or setting and receive matching books from a sample catalog. It includes a custom cursor, ambient book and pencil icons that move away from the pointer, genre and availability filters, sample story prompts, and a demo request flow.

[Open the Day 2 notebook](Day%202%20-%20Storybound%20Library/Storybound_Library.ipynb)

> Storybound's catalog and request flow are sample data for the course project; they are not connected to a real library.
